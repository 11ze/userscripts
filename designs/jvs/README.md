# JVS 界面预览

运行 `python3 -m http.server 4311 --directory designs`，打开 `http://localhost:4311/jvs/`。入口自动进入统一预览页 `app-center.html`：应用中心、日志按钮和日志浮窗在同一页展示。

参考 `src/jvs.user.js` 中的 `MODE_COLORS`、`showLogPopup`、`highlightApps`、`filterStarredApps`、`toggleAppCenterSidebar` 以及 `docs/scripts/jvs.md` 中的用户否决记录。没有绑定独立设计系统。

宿主布局与应用数据为示意，未修改用户脚本。应用入口仅显示点击反馈；日志名称在新标签页打开示意地址。原型使用独立存储键，不读取用户脚本数据。

浏览器验证步骤：

- 日志初始收起，避免遮挡工具按钮示意。点击日志按钮、背景或 Escape 可关闭，日志按钮可重新打开。
- 拖动日志把手，浮窗跟随移动。名称单元格包含留白的区域均可点击，支持中键。
- 悬停卡片显示星标；已点亮的星标常显，卡片使用极浅金底、2px 浅金边框与放大的星形图标，不显示竖线或「星标」文字。
- 搜索、分类和「只看星标」可以组合使用。无匹配时显示空态，无匹配卡片的分组隐藏。
- 收起侧栏后卡片区扩展；刷新后保留星标、筛选和侧栏状态。

独立原型采用浏览器验证，未新增自动化测试。

工具按钮示意位于搜索栏下方，展示查看逻辑、复制名称、复制组件名称和清空字段。复制写入剪贴板；查看和清空只显示反馈。日志栏使用局部基础按钮样式，不依赖宿主默认样式。
