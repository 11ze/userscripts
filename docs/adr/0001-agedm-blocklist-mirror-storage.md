# agedm 屏蔽名单采用 GM 主存 + 域名本地镜像双存储

Tampermonkey 导出/导入脚本时按 key 整包覆盖 GM 存储，另一台设备的空/旧名单会顶掉本机名单；而 AGE 动漫镜像域名经常换，纯 localStorage 又随域名丢失。决定名单双写两处（GM `agedmBlockedNames` + 当前域名 localStorage `agedm-blocked-11ze`，值格式 `{list, at}`），启动时裁决一次：一边有键用一边，两边有键比 `at` 新者胜（相同视为 GM 胜），胜者按原 `at` 回写两边（旧版裸数组视为 `at=0`，首次回写即升级格式）；清空 = 两边删键，不留"空但有键"的状态。

## Considered Options

- **GM 第二 key 影子备份**：双向导出导入后，对方设备也会写下自己的影子 key，导入时连同影子一起被覆盖，保护只对"对方从未运行过新版脚本"的一次性窗口有效。否决。
- **纯 localStorage**：对导入免疫，但绑定域名，换镜像域名即失效。否决，保留为镜像层。

## Consequences

- 两边都有键且对方那份更新时，本机较旧名单被对方版本顶掉——这是"哪边新用哪边"的既定语义，不是数据丢失 bug。
- "刚换域名就遭遇导入覆盖"的双连击仍会丢名单（新域名镜像尚未写、GM 已被清空），概率低，接受。
