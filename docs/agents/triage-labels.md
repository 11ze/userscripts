# Triage Labels

技能用五个标准分诊角色沟通。本文件把角色映射到本仓库议题跟踪器实际使用的标签字符串。

| 技能里的角色      | 跟踪器里的标签    | 含义                 |
| ----------------- | ----------------- | -------------------- |
| `needs-triage`    | `needs-triage`    | 待维护者评估         |
| `needs-info`      | `needs-info`      | 等待报告者补充信息   |
| `ready-for-agent` | `ready-for-agent` | 已写清，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现         |
| `wontfix`         | `wontfix`         | 不予处理             |

当技能提到某个角色（如「打上 AFK-ready 分诊标签」），使用表中对应的标签字符串。

改右列即可匹配你实际使用的词汇。
