# age-video-download.user.js 架构

- **剪贴板跨页传名**：按钮页与新标签页是两个独立页面，当前用剪贴板传递文件名（按钮页写入，新标签页读出作 `<a download>` 文件名）。
- **异步顺序**：点击时同步打开空白标签页，名称写入剪贴板成功后再导航，防止等待写入后丢失弹窗授权；写入失败关闭空白页，按钮可重试。弹窗被拦截时不写剪贴板。
- **轮询终止**：按钮挂载或下载链接触发后停止轮询；剪贴板读取中不重入，失败后下一 tick 重试。链接触发成功不代表浏览器已完成下载，仍受剪贴板权限和浏览器下载策略限制。
- **已知问题**：按钮用 `newTabButton.class =` 赋类名无效（应为 `className`），按钮实际无样式类，改动会有视觉变化故暂留。

自动验证：`node --test tests/age-video-download.test.mjs`。

浏览器验证：agedm 播放页点 📺 后观察新标签页自动下载、文件名与标题为剪贴板内容。
