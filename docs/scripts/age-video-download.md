# age-video-download.user.js 架构

- **剪贴板跨页传名**：按钮页与新标签页是两个独立页面，当前用剪贴板传递文件名（按钮页写入，新标签页读出作 `<a download>` 文件名）。
- **异步顺序**：点击时同步打开空白标签页，名称写入剪贴板成功后再导航，防止等待写入后丢失弹窗授权；写入失败关闭空白页，按钮可重试。弹窗被拦截时不写剪贴板。
- **轮询终止**：按钮挂载或下载链接触发后停止轮询；剪贴板读取中不重入，失败后下一 tick 重试。链接触发成功不代表浏览器已完成下载，仍受剪贴板权限和浏览器下载策略限制。
- **按钮样式（v0.2.7）**：旧代码用 `newTabButton.class =` 赋类名，属性名写错导致样式从未命中；改为 `className` 后按钮走 `<style id="11ze-age-video-button-style">` 里的 30px 图标钮（圆角 8、灰底、hover/`:focus-visible`/`:active`/`:disabled`），内联 SVG 播放图标替换 📺，`aria-label`/`title` 为「在新页面播放并下载视频」。
- **颜色跟随文字**：按钮底色与描边用半透明灰、图标 `currentColor`，深色 AGE 页与浅色页都不突兀；没有照搬 agedm 的站点红，避免在播放页抢标题。

自动验证：`node --test tests/age-video-download.test.mjs`。

浏览器验证：agedm 播放页观察标题旁的 30px 播放入口，点击后确认新标签页自动下载、文件名与标题为剪贴板内容。
