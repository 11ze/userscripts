# anime_search.user.js 架构

- **SPA 换页不补挂**：一次性执行，站内换页后按钮不补挂——用户决策：刷新页面即可，不为该场景加轮询。
- **标题提取不做正则剥字**：防误剥标题原文；自挂按钮不进标题（提取跳过 button 子树）。
- **选择器失效史**：B 站 2026-08 改版后 `#__next` 6 层 div 旧选择器已失效，现用媒体信息区标题链接的 class 前缀匹配。
- **装配表**：站点 → 标题选择器 + 按钮工厂序列 + 站点级 CSS 一张表（SITE_SETUP），主循环只剩「该站选择器依序找标题 → 挂该站序列」——加站/加按钮改表不动控制流（v0.6.16/17 连续两版在主循环中间动刀的前科；v0.6.19 前站点选择器还在表外的跨站扁平表里，加站要改两处）。站点差异（选择器序列、AGE 站内搜索、详情钮、CSS 屏蔽）只准写在各自条目里，不得回到主循环做 `site ===` 分支。
- **搜索标题编码**：拼搜索 URL 前对标题 encodeURIComponent——含 `&` / `#` 的标题未编码会被解析为参数分隔符或 fragment，截断查询串（v0.6.19 前科）。

验证：`node --test tests/anime_search.test.mjs`。
